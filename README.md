# Cron Talk (#56)

A hyper-minimalist Cron expression translator for the Fridge Combo series. This tool converts complex, symbolic Cron patterns into plain, human-readable English to prevent configuration errors.

## Core Philosophy
- **1 Tool / 1 Action**: Purely for translating Cron expressions. No execution, no tracking.
- **Privacy First**: Browser-only execution. Your configurations never leave your device.
- **High Reliability**: Handles ranges, steps, and multiple values with precise English output.

## Features
- **Real-time Translation**: Instant feedback as you type.
- **Validation**: Immediate error reporting for invalid Cron formats or values.
- **Quick Examples**: One-tap access to common schedules (Daily, Office Hours, Monthly).
- **Mobile Optimized**: Designed specifically for iPhone Safari and Android Chrome with "Add to Home Screen" support.

## UI Standards
- **Background**: #fff
- **Main Text**: #333 (Optimized for visibility)
- **Radius**: 15px (All elements)
- **No login / No tracking / No ads**

## How to Install
1. Open the tool in your mobile browser.
2. Tap the **"Add to Home Screen"** button or use your browser's share menu.
3. Access it anytime as a standalone web app.
